# Lua Playground

A browser-based playground for experimenting with Lua code using a JavaScript-powered Lua interpreter.

**Live Demo:** [Lua Playground on GitHub Pages](https://expdev-mul.github.io/Lua-Playground/)

## Features

- Run Lua code directly in the browser
- Minimalist and responsive UI
- No installation or setup required

## Usage

1. Clone the repository:
   ```bash
   git clone https://github.com/ExpDev-mul/Lua-Playground.git
   ```
2. Open `index.html` in any modern web browser.

## Notes

This project is built entirely with HTML, CSS, and JavaScript. It uses a browser-compatible Lua interpreter (such as fengari) to execute Lua scripts. Ideal for quick testing or learning Lua basics.
